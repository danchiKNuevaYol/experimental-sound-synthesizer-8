# Experimental Sound Synthesizer

Веб-синтезатор искусственных природных звуков. Дождь, ветер, гроза, лес и фантастические явления
собираются вручную из шума и простых волн — **без готовых записей и сэмплов**.

Стек: обычные HTML, CSS и JavaScript-модули, звук — [Tone.js](https://tonejs.github.io), дисплей —
[p5.js](https://p5js.org), запуск и сборка — [Bun](https://bun.sh). Без React и без фреймворков.

## Запуск

Нужен Bun 1.2 или новее. Установка на Mac: `brew install oven-sh/bun/bun`
(или `curl -fsSL https://bun.sh/install | bash`).

```bash
bun install      # скачает Tone.js и p5.js в node_modules
bun run dev      # откроется адрес из консоли, обычно http://localhost:3000
bun run build    # готовая сборка в папке dist/
```

В VS Code: откройте папку проекта, терминал `Ctrl + ~`, затем команды выше.
Звук включается кнопкой ▶ или пробелом — браузер не разрешает автозапуск звука без действия пользователя.

## Концепция

Природа здесь не воспроизводится, а **собирается** из простых электронных сигналов: розовый шум через
дышащий фильтр становится ветром, высокий синус с блуждающей высотой — свистом, короткий удар мембраны —
каплей. Пользователь сам конструирует звуковую среду и управляет её развитием в реальном времени.

## Как устроен звук

```
ГОЛОС A · АТМОСФЕРА   шум / волна → фильтр (+LFO «дрейф»)            → КАНАЛ A ┐
ГОЛОС B · ЭЛЕМЕНТЫ    волна + шум → фильтр → вибрато / тремоло       → КАНАЛ B ┤
ЧАСТИЦЫ               капля · щелчок · треск · раскат (16 шагов)     → КАНАЛ Ч ┤
                                                                               ▼
КАНАЛ (A, B, Ч — у каждого свой):                            ОБЩИЙ КАНАЛ:
Драйв → Модуляция → Эхо → Реверб → громкость → панорама      яркость → громкость → лимитер
                                   └ индикатор уровня                   → выход и запись (WAV)
```

- **Два голоса и частицы** — три независимых источника.
- **У каждого канала своя цепочка эффектов** из четырёх звеньев. Эхо привязано к темпу и у каждого
  канала своё (A — пунктирная восьмая, B — восьмая, Ч — короче), длина реверберации тоже разная.
- **Звук разведён по каналам**: у A, B и частиц своя громкость, панорама и индикатор уровня,
  затем они сходятся в общий канал.

## Интерфейс

| Блок | Что делает |
|---|---|
| Голос A · Атмосфера | Фон: ветер, гул, шелест. Форма волны, ТОН, ФОРМА (резонанс), ДРЕЙФ (дыхание фильтра), УРОВЕНЬ |
| Дисплей | Что звучит в голосах, уровни трёх каналов, спектр выхода, 16 шагов, темп, открытая цепь |
| Голос B · Элементы | Свист, вибрации, раскаты. ТОН, ФАКТУРА (шум и резонанс), ВИБРО, УРОВЕНЬ |
| Эффекты · Цепь | Вкладки A / B / Ч выбирают канал; ручки — его цепочка: 1 ДРАЙВ → 2 МОДУЛ. → 3 ЭХО → 4 РЕВЕРБ |
| Ритм · Частицы | 16 шагов × 4 дорожки; справа случайный узор, сдвиг влево/вправо, сброс |
| Микшер · Каналы | A, B, ЧАСТИЦЫ, ОБЩИЙ: сверху панорама (у общего — яркость), индикатор, фейдер громкости |
| Запись | Большая кнопка пишет исполнение, «⭳» скачивает WAV |
| Сцены | Ветер, Дождь, Гроза, Лес, Неземное — готовые настройки одним нажатием |

**Ручки**: зажмите и ведите курсор вокруг ручки — стрелка смотрит на курсор (чем дальше отвести мышь,
тем точнее). Колесо и стрелки клавиатуры тоже работают, двойной клик — значение по умолчанию.

### Горячие клавиши для живого исполнения

| Клавиша | Действие |
|---|---|
| Пробел | старт / стоп |
| R | начать / закончить запись |
| 1 – 5 | сцены: Ветер, Дождь, Гроза, Лес, Неземное |
| Q / W / E | открыть цепочку эффектов A / B / Частиц |

## Нейминг компонентов

Один принцип на всё: **имя блока = CSS-класс = файл стилей = JS-модуль**. Классы — по БЭМ:
`блок__элемент--модификатор`, состояния — `is-on`, `is-now`, `is-drag`.

| Блок | Разметка | Стили | Логика |
|---|---|---|---|
| Корпус | `.device` | `blocks/device.css` | `main.js` (масштаб) |
| Панель | `.panel`, `.panel__title` | `blocks/panel.css` | — |
| Кнопка корпуса | `.key`, `.key--small` | `blocks/key.css` | — |
| Сцены | `.scene-bar` | `blocks/scene-bar.css` | `ui/scene-bar.js` |
| Форма волны | `.wave-switch` | `blocks/wave-switch.css` | `ui/wave-switch.js` |
| Ручка | `.knob` | `blocks/knob.css` | `ui/knob.js` |
| Дисплей | `.display` | `blocks/display.css` | `ui/display.js` (p5) |
| Цепочка эффектов | `.fx-rack` | `blocks/fx-rack.css` | `ui/fx-rack.js` |
| Сетка шагов | `.step-grid` | `blocks/step-grid.css` | `ui/step-grid.js` |
| Микшер | `.mixer`, `.mixer__strip` | `blocks/mixer.css` | — |
| Фейдер | `.fader` | `blocks/fader.css` | `ui/fader.js` |
| Индикатор уровня | `.meter` | `blocks/meter.css` | `ui/meter.js` |
| Запись | `.recorder` | `blocks/recorder.css` | `ui/recorder.js` |
| Экран записи | `.lcd` | `blocks/lcd.css` | `ui/recorder.js` |

**Каналы** везде называются одинаково: `a` — голос A, `b` — голос B, `p` — частицы, `master` — общий.
Отсюда модификаторы цвета (`knob--a`, `key--b`, `fx-rack--p`, `dot--master`) и переменные цвета
в `theme.css` (`--ch-a`, `--ch-b`, `--ch-p`, `--ch-master`). Цвет канала один на всё: точка
в заголовке, колпачок ручки, кнопка, вкладка цепочки, столбики на дисплее.

**Параметры** подключаются в разметке атрибутом `data-param` — это путь в состоянии:
`data-param="a.tune"`, `data-param="mix.p"`, `data-param="fx.*.delay"` (звёздочка — канал,
чья цепочка сейчас открыта). Чтобы добавить ручку, достаточно написать в `index.html`
`<div class="knob" data-param="..." data-label="..."></div>` — JS найдёт её сам.

## Структура проекта

```
index.html                 разметка всего прибора
package.json               зависимости и команды Bun
src/
  main.js                  сборка прибора из разметки, транспорт, запись, горячие клавиши, масштаб
  audio/engine.js          звуковые цепочки на Tone.js
  audio/wav.js             экспорт записи в WAV
  state/store.js           хранилище состояния и пути параметров
  state/scenes.js          звуковые сцены и начальное состояние
  ui/*.js                  компоненты интерфейса (по одному на блок)
  styles/
    index.css              подключает всё по порядку
    fonts.css              ← шрифты
    theme.css              ← цвета и размеры
    base.css               общие правила
    blocks/*.css           стили блоков (по одному на блок)
```

## Как поменять шрифт

Поменяйте ссылку Google Fonts в `index.html` и имена в `src/styles/fonts.css`
(`--font-display`, `--font-ui`, `--font-mono`). Шрифт нужен с кириллицей.
Для показа без интернета положите `.woff2` в `src/styles/fonts/` и раскомментируйте `@font-face`
в `fonts.css`.

## Как добавить свою сцену

В `src/state/scenes.js` добавьте объект в массив `SCENES` по образцу: формы волн и ручки голосов,
цепочки эффектов трёх каналов, микшер, темп и узор на 16 шагов. Кнопка появится в шапке сама,
клавиша — следующая по номеру.

## Загрузка на GitHub через GitHub Desktop

1. **File → Add Local Repository…** → выберите папку проекта. Если GitHub Desktop предложит
   «create a repository» — согласитесь.
2. Слева внизу напишите сообщение коммита и нажмите **Commit to main**.
3. **Publish repository** → снимите галочку «Keep this code private», если ссылка нужна для просмотра.
4. Ссылка на репозиторий: **Repository → View on GitHub**.

Папки `node_modules/` и `dist/` в репозиторий не попадают (см. `.gitignore`), а файл `bun.lock`,
который появится после `bun install`, коммитить нужно — он фиксирует версии библиотек.
